## Build and install

On Windows with JDK 17 and Android SDK platform/build-tools 36 already installed:

```powershell
pwsh -File apps/social-mobile/scripts/build-apk.ps1
adb install -r apps/social-mobile/dist/AliaSpaces-0.4.0-akasha-local-signed.apk
adb shell am start -a android.intent.action.VIEW -d aliaspaces://local -n com.aliaspaces.social.local/.MainActivity
```

The script runs Android tests/build, checks the signature, verifies the packaged
web allowlist against source hashes, and writes SHA256SUMS.txt beside the APK.
It uses a socket-temp directory without spaces for the Windows JDK workaround.
The existing Bash helper is historical and has not been requalified here.
